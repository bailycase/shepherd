`ProjectSettingsStore` and `ProjectsModel`. Credential and host replies are fixture data, never
live projects or credentials. These are the real views, not mockups.

Each of the 22 cases has light and dark renders at text scales 1.0 and 1.3. The blocked case
also covers Pi's saved denial, since both prevent project resources from loading.
